# Project-mvp Frontend UI/UX 가이드라인

이 문서는 프로젝트의 공통 UI/UX 원칙을 정의합니다. 모든 코드 생성 및 UI 구현 시 아래 가이드라인을 엄격히 준수하십시오. 

## 1. 컬러 시스템 (Color Palette)
모든 스타일은 CSS 변수를 사용하여 라이트/다크 모드를 대응합니다. 

| 구분 | 변수명 | 라이트 모드 | 다크 모드 |
| :--- | :--- | :--- | :--- |
| 배경색 | `--bg` | `#F8F9FA` | `#121212` |
| 카드 배경 | `--card` | `#FFFFFF` | `#1E1E1E` |
| 기본 텍스트 | `--text` | `#212529` | `#ECECEC` |
| 보더/구분선 | `--border` | `#E9ECEF` | `#2C2C2C` |
| 포인트 컬러 | `--kb-yellow` | `#FFCC00` | `#FFCC00` |

## 2. 레이아웃 규칙
* [cite_start]**전체 여백**: `body` 요소에는 `40px`의 패딩을 적용한다. [cite: 4]
* [cite_start]**컨테이너**: 메인 콘텐츠 최대 너비는 `600px`, 중앙 정렬(`margin: 0 auto`)을 사용한다. [cite: 5, 6]
* **그리드**: 카드 레이아웃은 `1fr` 단일 컬럼 그리드, `gap: 20px`를 사용한다. [cite: 11]
* [cite_start]**헤더**: `flex` 레이아웃과 `justify-content: space-between`을 적용한다. [cite: 7]

## 3. 컴포넌트 상세 스타일
### 카드 (Card)
* [cite_start]**기본**: 패딩 `25px`, `border-radius: 20px`, 그림자 `0 10px 20px rgba(0,0,0,0.05)` [cite: 11, 12]
* **AI 추천 박스**: 테두리에 `2px solid var(--kb-yellow)` 추가 [cite: 14]

### 버튼 (Mode Toggle)
* [cite_start]**형태**: 알약 모양 (`border-radius: 30px`) [cite: 9]
* [cite_start]**색상**: 배경 `var(--kb-yellow)`, 텍스트 `#000` (bold) [cite: 9]
* **효과**: 그림자 `0 4px 15px rgba(255, 204, 0, 0.4)` [cite: 10]

### 타이포그래피
* [cite_start]**금액 (Amount)**: `32px`, `bold` [cite: 13]
* [cite_start]**경고 문구**: 컬러 `#ff5252`, `13px`, `bold` [cite: 16]
* **AI 뱃지**: 배경 `var(--kb-yellow)`, 텍스트 `#000`, `10px`, `bold` [cite: 17]

## 4. 인터랙션
